# Fake-News-Detector-Text-Based-
A machine learning project that classifies news articles as real or fake using NLP techniques ,TF-IDF and Random Forest.

## Project Overview

This project is a text-based Fake News Detection system that classifies news articles as Real or Fake using Natural Language Processing (NLP) techniques. The model uses TF-IDF Vectorization for feature extraction and Random Forest Classifier for prediction.

## Features

* Text preprocessing using NLP
* TF-IDF feature extraction
* Random Forest classification
* Real/Fake news prediction
* Model evaluation using accuracy and confusion matrix

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* NLP
* TF-IDF Vectorizer
* Random Forest Classifier
* Google Colab

## Dataset

The dataset contains news articles and their corresponding labels:

* 0 = Fake News
* 1 = Real News

## Workflow

1. Data Collection
2. Data Preprocessing
3. TF-IDF Vectorization
4. Train-Test Split
5. Random Forest Model Training
6. Prediction
7. Performance Evaluation

## Output

The model predicts whether a news article is:

* Real News
* Fake News
